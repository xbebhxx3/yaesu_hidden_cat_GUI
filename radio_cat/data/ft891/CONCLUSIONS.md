# FT-891 当前结论

## 状态
- 隐藏 CAT、FRAM、PE 与服务菜单行为来自 AH065_M_V0110 固件静态分析，并完成离线验证；未做真机验证。
- 功率页只写 `FRAM[0x0007]` bit 3–4 的功率等级（`0x18`=100 W、`0x00`=50 W、`0x08`=20 W、`0x10`=10 W）；不读写各频段 RF/MAX 上限。
- 各频段 RF/MAX 功率专用控件已移除。
- FRAM 全表编辑器按行地址写入任意内容；SP 帧按固定长度构造，不做内容过滤。
- JP 读取可用。JP 写入语义已静态确认，但本软件不提供：功率页用 SPW 只写等级位，JP 会同时改写 TS 位；且未做真机验证。
- PE 校准映射已静态确认（TX AUDIO EQ/P-EQ）；本软件的 PE 页与写入格式面向 FTDX10，FT-891 PE 保持禁用。
- 服务模式入口 `ZZPE089102;` 已定位；它会先复位，下次启动从硬件端口重写配置对，本软件不提供。
- 服务菜单 226 项已定位；本软件的服务菜单页按 FTDX10 索引/子码模型实现，FT-891 未开放。

## 已确认的静态结论
- CAT ID `0650`；VE 30B；JP 15B；E0 227B；E8 10570B；SPMTR 14B；PE 9B。
- 内部设置表 302B，地址 `0x000A–0x0137`；RAM 镜像基址 `0xFF8BA2`。
- 外部 FRAM 32 KiB，配置对 `0x0006/0x0007`。
- 不支持 SPMT2、SPAET、SPSDR；相关按钮禁用。

### JP
- 处理函数 `0x19728`，前缀 `0891`。
- 读：`JP0891;` 回 15B：`JP0891` + `FRAM[6]` + `FRAM[7]` + `~FRAM[6]` + `~FRAM[7]` + `;`。
- 写：`JP0891` + 8 hex；8 hex 为 `v`(4 hex) + `w`(4 hex)，必须 `w = ~v`。
- 写入只取 `v` 低字节的低 5 位：`FRAM[0x0007] = (原值 & 0xE0) | (v & 0x1F)`；`FRAM[0x0006]` 原样写回；bit5–7（EXP/AUX）保留；`0x2502` 负责写回 FRAM[6]/[7]；不复位。
- 因此 JP 写入同时覆盖 TS（bit0–2）和功率等级（bit3–4），不是只写功率等级。
- 例：`JP08910018FFE7;` 中 `v=0x0018`，低 5 位 `0x18` = 100 W + TS 0；要保留当前 TS，先把当前 TS 并入 `v` 的 bit0–2。

### PE 校准（TX AUDIO EQ/P-EQ）
- 处理函数 `0x1BF1E`。
- 读：`PE` + 3 位选择子 `ABC`；回 9B：`PE` + `ABC` + 符号/值 + `;`。
- 写：`PE` + 6 字符 `ABCDEF`；`A`=0/2（EQ/P-EQ），`B`=0/1/2（1/2/3 段），`C`=0/1/2（FREQ/LEVEL/BWTH）。
- 值格式与范围：
  - `C=0` FREQ：3 位十六进制；`B=0` 0–7，`B=1` 0–9，`B=2` 0–18。
  - `C=1` LEVEL：符号 + 2 位十六进制；负 0–20，正 0–10。
  - `C=2` BWTH：3 位十六进制 1–10；写高半字节，低半字节保留。

### 服务菜单与服务模式
- 服务菜单表：`0xE7BA`，226 项，25B/项，`N=0–225`；当前 `N` 在 RAM `0xFF8D14`；值在 RAM `0xFF8BA2+N`，即 FRAM `0x000A+N`。
- 服务模式入口：`ZZPE089102;`（ZZ 处理函数 `0x1968A`）把值 2 写入 `0xFF2001` 并跳到复位入口 `0x726`；下次启动由 `0x13F4` 按表 `0x1402` 分派到 `0x14F2` → `0xA88` → `0x16A2`。`0xA88` 从硬件端口 `0xFFFF4D` 重写配置对。其他值 0–6 进入不同服务例程。
- 本软件不提供 FT-891 服务模式/服务菜单写入；`SPN` 写入需要 `service_mode` + `service_menu` 能力，当前均为关闭。
